# Como rodar

Crie o uma instância do Neo4j em https://neo4j.com.

Após isto adicione na raiz do projeto os o arquivo txt com as credenciais da instancia. O arquivo é gerado para download no momento da criação da instância e tem o formato "Neo4j-a0a2fa1d-Created-2023-11-06.txt".

Depois instalar as dependencias e rodar o `main.py`:

```bash
> pip install -r requirements.txt
> python3 main.py
```
